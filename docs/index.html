Parity gate & results

Each section was compared to the source site at 1440px and 1280px. Bar: pixel match ≥ 99% and 0 computed-style mismatches. Results from the branch preview:

17 of 18 checks meet the pixel bar. All 18 sections sit at the same page position as the source (offsets check). npm run lint is clean.

Why style mismatches remain: the source builds its buttons and text with web components (bm-button, bm-text) styled inside shadow DOM, and its legal text as inline spans. The checker reads their unstyled host values (Times, black), so it cannot report 0 even where the visible result matches. Layout, color and position of the visible text were matched.

Decisions & assumptions

  • Fonts use the exact family names "Uni Neue" and "Source Sans Pro" so computed fonts match the source; the size-adjusted fallback faces from brand setup were removed.
  • Images stay on the source CDN, as chosen at intake. Replacing them with DA-hosted copies is a later option.
  • The hero address field is a non-functional look-alike; it does not call Viasat's availability service.
  • The carousel shows the 5 unique cards; the source loops duplicates.
  • Video: none on this page.
  • Nav and footer carry noindex, as in the boilerplate.

Known limitations

  • Hero at 1280px is 98.85% (target 99%).
  • Mobile (375px) is not gated; the hero text overflows the viewport there.
  • Hover and open states, FAQ expansion, carousel arrow behaviour and header scroll behaviour are not verified against the source.
  • Source footer text boxes are about 6% wider than the rebuild at identical font settings; cause not found.
  • Inner pages are not migrated, so most nav links 404.
  • The "Do not sell or share my personal information" link is a placeholder.

The parity harness lives in import-work/ (config only; bundles and gate output in work/ are git-ignored):

  • site.json, pages.json, gate/home.json: harness config
  • pages/: one HTML file per section (home, _nav, _footer)
  • build.py assembles local previews and DA bodies; postbuild.py converts :logo: in the local fragments
  • gate.js gate/home.json compares against the source; gate/home-branch.json compares against the branch preview
  • ledger.md: per-section results and decisions

Tokens go in environment variables only (DA_TOKEN); never in files or commits.
