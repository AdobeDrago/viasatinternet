# cards-addons

Custom **cards** block. Purpose: Shadowed photo cards with title, description and a divider + icon offer footer.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: [photo | h3 title, description paragraph, offer paragraph starting with an icon (":tag: Get your first month FREE")].

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Usage

"Enhance your online experience" add-on cards on plans.

## Reuse guidance

Author as "Cards Addons". The last paragraph starting with an icon becomes the offer footer.
