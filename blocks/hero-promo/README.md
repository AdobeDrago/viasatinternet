# hero-promo

Custom **hero** block. Purpose: Rounded promo banner with background image and two text groups.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2 (one cell): heading + CTA link (left group), second heading + disclaimer paragraph (right group); the split is made at the second heading. An optional short paragraph before the first heading renders as an eyebrow label (e.g. "LIMITED-TIME OFFER") and switches both headings to the compact 28px size.

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Usage

Homepage promo banner ("Order Viasat Essentials or Unleashed" / "Save $360 ...").

## Reuse guidance

Author as "Hero Promo". Keep both groups in one cell; the second heading starts the right-hand group.
