# carousel-cards

Custom **carousel** block. Purpose: Slider of look-alike icon cards (title + text above an icon image), several visible at once.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide: [icon image | h3 title, paragraph].

## Supported variations

No variations.

## Universal Editor fields

N/A (Document Authoring project)

## Usage

"Why people choose Viasat" sliders on home (5 slides) and plans (6 slides).

## Reuse guidance

Author as "Carousel Cards". Author only the unique slides (the source repeats slides for looping); prev/next wrap around.
